데이터 삭제 요청 안내

앱: 나의엄마 - 가족 냉장고 (iomma) · 개발자: 이옥태 · 최종 수정일: 2026년 10월 11일

1. 이 기기에 저장된 데이터 지우기

냉장고 목록, 추억 메모, 설정은 기본적으로 휴대폰 안에만 저장됩니다. 아래 방법으로 언제든 직접 지울 수 있습니다.

  • 앱을 삭제하거나
  • 휴대폰 설정 → 애플리케이션 → 나의엄마 → 저장공간 → 데이터 삭제를 누르세요.

2. 가족 공유(클라우드)에 저장된 데이터 삭제 요청

가족 공유를 켠 경우 냉장고 목록이 Google Firebase 서버에 저장됩니다. 삭제를 원하시면 다음 순서로 요청해 주세요.

  1. 앱에서 👨‍👩‍👧 가족 공유 버튼을 눌러 가족 코드 8자리를 확인합니다.
  2. lot5665@gmail.com으로 제목 "[나의엄마] 데이터 삭제 요청", 내용에 가족 코드를 적어 메일을 보냅니다.
  3. 요청을 받은 날부터 7일 이내에 삭제하고 메일로 알려드립니다.

3. 삭제되는 데이터

  • 해당 가족 코드에 저장된 냉장고 식재료 목록(이름, 보관 위치, 날짜)
  • 추억 메모와 칸 설정
  • 가족 코드와 마지막 수정 기기를 구분하는 무작위 식별값

4. 보관되는 데이터와 보관 기간

  • 가족 공유 데이터는 요청 후 모두 삭제되며 따로 보관하지 않습니다.
  • Google 애널리틱스의 앱 사용 통계(개인을 알아볼 수 없는 정보)는 Google 설정에 따라 최대 14개월 보관된 뒤 자동으로 삭제됩니다.

자세한 내용은 개인정보처리방침을 참고해 주세요.
